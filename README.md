# Safdar Chougle Portfolio

## How to Run Locally

### Clone the repository

```bash
git clone https://github.com/your-username/portfolio.git
cd portfolio
```

### Install dependencies

```bash
npm install
```

### Run development server

```bash
npm run dev
```

### Open in browser

```bash
http://localhost:3000
```
